audiospace 0.7.0　はじめにお読みください

audiospace は、視覚障害者向けのゲームやツールのための、ヘッドホンで聞く3D音響の部品（ライブラリ）です。
音の聞こえる方向や響きを確かめる「定位確認ツール」が付いています。どちらもキーボードとスクリーンリーダー（PC-Talker・NVDA）だけで使えます。
画面と読み上げは、Windows の表示言語が日本語なら日本語、それ以外なら英語になります。


■ このフォルダの中身

ファイルが16個、フォルダが5つあります。

・はじめにお読みください.txt は、このファイルです。
・マニュアル.html と マニュアル.txt は、使い方の説明です。中身は同じです。html はブラウザで開くと見出しで移動でき、txt はメモ帳などで上から順に読めます。
・定位確認ツールを起動.bat は、定位確認ツールを起動します。先に Python と部品を入れておく必要があります（下の「最初の3歩」）。
・README.md は、ゲームに組み込む人向けの詳しい説明です。
・CUES.md は、前後と上下の聞き分けを助ける処理の一覧です。
・LICENSE は、ライセンス（MIT）の全文です。英語です。
・ATTRIBUTION.md は、同梱しているデータの出典と表示の決まりです。
・pyproject.toml は、部品を入れるときに使う定義のファイルです。
・次のファイルは、上のファイルの英語版です（海外の利用者向け）。README (English).txt（このファイル）、Manual (English).html と Manual (English).txt（マニュアル）、Start Localization Tool.bat（同じ起動用の bat）、README.en.md、CUES.en.md、ATTRIBUTION.en.md。
・audiospace フォルダは、ライブラリの本体です。
・assets フォルダは、実測の頭部伝達関数（耳の形ごとの音のデータ）と、計算済みの残響です。
・demo フォルダは、定位確認ツールの本体です。
・tests フォルダは、動作を確かめるテストです。
・tools フォルダは、データを作り直す道具などです。使うだけなら要りません。

定位確認ツールを使うと、このフォルダの中に logs フォルダ（聴き取りの結果）と settings フォルダ（自分で作った空間と残響）が増えます。


■ 最初の3歩

1. このフォルダを、「ドキュメント」など自分が書き込めるフォルダに置きます。「Program Files」の中には置かないでください。
2. Python 3.10 以降を入れ、このフォルダでコマンドプロンプトを開いて、次の1行を実行します。
   python -m pip install -e ".[app]"
   「python が見つかりません」と言われたら、先頭の python を py に替えて実行します。
   詳しい手順は、マニュアルの「3. 準備」にあります。
3. 定位確認ツールを起動.bat を開きます。「定位確認 - audiospace」という窓が開き、キー操作の説明が読める状態になれば準備完了です。F1 キーでキー操作の説明の窓が開きます。

ヘッドホンを使ってください。スピーカーでは左右の音が混ざるため、方向が分かりません。


■ 終了のしかた

定位確認ツールは Escape キーで終了します。

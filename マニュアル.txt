audiospace 0.7.0 マニュアル

作者: Takahashi。この文書は2026年10月16日に作りました。
audiospace は、視覚障害者向けのゲームやツールのための、ヘッドホンで聞く3D音響の部品（ライブラリ）です。音の聞こえる方向や響きを確かめる「定位確認ツール」が付いています。どちらもキーボードとスクリーンリーダー（PC-Talker・NVDA）だけで使えます。

付録: 材質の一覧

■ 1. はじめに

ヘッドホンで聞く音は、そのままでは頭の中で鳴っているように聞こえます。audiospace は、音が頭の外の決まった方向と距離から届くように加工します（バイノーラル処理）。耳の形で音がどう変わるかを実測したデータ（頭部伝達関数、HRTF とも言います）を使うので、左右だけでなく、前後や上下も表せます。

◆ できること

・音を、聞き手の周りの好きな方向と距離に置き、動かす
・部屋の響き（残響）を付ける。部屋の材質（木、コンクリート、じゅうたんなど）や、置いてある家具や人の数で響きが変わる
・前後と上下を聞き分けやすくする工夫（後ろの音をこもらせる、上の音を明るくする、頭を小さく振る、など）
・耳の形の違う20種類の実測データから、自分に合うものを選ぶ

◆ 定位確認ツール

定位確認ツールは、音がどの方向から聞こえるかを確かめ、聞き分けを練習するための画面です。クイズで成績を測ったり、自分に合う耳の形のデータを選んだり、部屋の響きを聞き比べたりできます。ゲームを作る人が、音の聞こえ方を確かめるのにも使えます。

◆ この文書の読み方

定位確認ツールを使うだけなら、2章から順に読んでください。ゲームに組み込む人は、3章で部品を入れたあと13章へ進んでください。キーだけを知りたいときは12章に一覧があります。

■ 2. 動作環境

・Windows 11 で確かめています。スクリーンリーダーは PC-Talker と NVDA で確かめています
・Python 3.10 以降が要ります（作者の環境は 3.14.5）
・ヘッドホンが要ります。スピーカーでは左右の音が混ざるため、方向が分かりません

◆ 使う部品

部品は3章の手順でまとめて入ります。ライブラリだけなら numpy と scipy の2つで動きます。定位確認ツールには、さらに次の4つが要ります。
・wxPython: 画面を作る部品
・accessible_output2: スクリーンリーダーに読み上げさせる部品。無くてもツールは動きますが、ツールからの読み上げ（正解・不正解など）がなくなります
・sounddevice: 音を出す部品
・sofar: 実測の頭部伝達関数のファイル（.sofa）を読む部品

このほか、pyroomacoustics を入れると、自分で作った部屋の響きを精密に計算できます（9章）。無くても、用意した部屋の精密な響きは使えます。
作者の環境で確かめた版は、wxPython 4.2.5、numpy 2.4.6、scipy 1.17.1、sofar 1.2.3、sounddevice 0.5.5、accessible_output2 0.17、pyroomacoustics 0.10.1 です。

◆ 表示の言語

定位確認ツールとライブラリの表示（画面、読み上げ、結果、保存するファイル）は、Windows の表示言語（Mac では「優先する言語」の先頭）が日本語なら日本語、それ以外なら英語になります。海外の利用者向けの英語の表示です。言語を自分で決めたいときは、起動する前に環境変数 AUDIOSPACE_LANG を ja（日本語）か en（英語）にします。言語は起動したときに決まるので、変えたら起動し直してください。

■ 3. 準備

手順は4つです。最後の1つは任意です。

◆ 3.1 フォルダを置く

配布の zip を展開し、できたフォルダを「ドキュメント」など自分が書き込めるフォルダに置きます。「Program Files」の中には置かないでください。定位確認ツールは、このフォルダの中に結果の記録（logs フォルダ）と自分で作った空間（settings フォルダ）を書き込みます。
zip の展開は、エクスプローラーで zip ファイルを選び、アプリケーションキー（または Shift+F10）で開くメニューの「すべて展開」で行えます。

◆ 3.2 Python を入れる

python.org から Windows 用の Python を入れます。入れるときの最初の画面に「Add python.exe to PATH」というチェックボックスがあるので、オンにしてから「Install Now」を押してください。オンにしないと、次の手順で「python が見つかりません」と言われます。

◆ 3.3 部品を入れる

このフォルダでコマンドプロンプトを開き、1行のコマンドを実行します。
1. エクスプローラーでこのフォルダを開きます
2. Alt+D でアドレスバーへ移り、cmd と入力して Enter を押します。このフォルダを開いた状態のコマンドプロンプトが開きます
3. 次の1行を入力して Enter を押します。数分かかり、最後に「Successfully installed」で始まる行が出れば完了です

    python -m pip install -e ".[app]"

「python が見つかりません」と言われたら、先頭の python を py に替えて実行してください。その場合、4章で起動するときも同じ Python が使われます（起動用の bat は、python が使えなければ py を使います）。
自分で作った部屋の響きを精密に計算したいときは、続けて次も実行します（任意）。

    python -m pip install pyroomacoustics

◆ 3.4 動作を確かめる（任意）

同じコマンドプロンプトで次を実行すると、自動のテストが動きます。音は出しません。数分かかり、最後に「全件合格」と出れば、部品が正しく入っています。

    python -X utf8 tests\run_all.py

■ 4. 起動と終了

フォルダの中の「定位確認ツールを起動.bat」を開くと、定位確認ツールが起動します。エクスプローラーでこのファイルを選んで Enter を押してください。「Start Localization Tool.bat」も同じ働きです（英語の名前を付けた同じ bat です）。
「定位確認 - audiospace」という窓が開き、「状況」の欄にフォーカスが入ります。この欄には起動したときにキー操作の説明が入っているので、上下の矢印で読めます。F1 キーを押すと、同じ説明を専用の窓で読めます（Escape で閉じます）。
コマンドプロンプトから起動することもできます。このフォルダで次を実行します。

    python -X utf8 demo\localization_app.py

終了するときは、窓の中で Escape キーを押します。

◆ 起動しないとき

bat を開いても窓が開かず、黒い窓に英語の文章が出て止まったときは、何かが足りません。多くは3章の部品が入っていないことが原因です。黒い窓は何かキーを押すと閉じます。14章も見てください。

■ 5. 画面の構成

画面は1枚で、上から順に、設定の欄、「状況」の欄、「結果の一覧」が並んでいます。Tab キーで上から順に移動します。各項目の名前の括弧の中のキー（例えば Alt+H）を押すと、その項目へ直接移れます。
・設定の欄: HRTF（頭部伝達関数）、音の種類、響き、聞き分けを助ける設定、難易度など。変えるとすぐに反映されます
・状況: モードの案内や結果の文章が入る、読み取り専用の欄です
・結果の一覧: 回答の結果が1問ずつ並びます

設定は記録されず、起動するたびに起動時の値に戻ります。いまの設定は F9 キーで読み上げます。

■ 6. 基本の操作

どのモードでも、音が鳴ったらテンキーで答えます。テンキーの数字を使うので、NumLock をオンにしておいてください（オフだとテンキーが矢印などとして働きます）。答えるキーは12章の一覧にあります。

◆ 答える

方向を答えるモードでは、テンキーの並びがそのまま方向の配置です。8が前、2が後ろ、4が左、6が右、7が左斜め前、9が右斜め前、1が左斜め後ろ、3が右斜め後ろです。答えるとすぐに「1問目 正解。正解は前でした」のように読み上げ、少し間を置いて次の問題が鳴ります。

◆ 聞き逃したとき

・F4 キーで、いまの問題をもう一度鳴らします
・繰り返し再生（テンキーの0でオンとオフ、起動時はオン）がオンのときは、答えるまで問題の音を間を空けて鳴らし続けます。読み上げに紛れて聞き逃しても、待てば聞けます
・F6 キーで音と繰り返しを止めます

◆ 向きを変える

左右の矢印キーで、その場で15度ずつ向きを変えられます。音源は動かないので、自分が回ると前の音と後ろの音が逆向きに動きます。前後に迷ったときに有効です。方向は「いまの自分から見た方向」で答えます。
Page Up と Page Down で、顔を15度ずつ上と下に向けられます（真上と真下の90度まで）。上下の聴き取りでは、顔の向きにかかわらず「体から見た音の高さ」で答えます。

◆ 読み上げのキー

・F5: いまのモードの結果
・F9: いまの設定
・F10: 耳の形のデータ（耳介）の通算の成績（7章）
・F1: キー操作の説明の窓

■ 7. モードの使い方

モードは、採点しないものが3つ、採点するものが8つあります。モードはキーで始め、別のモードのキーを押すと切り替わります。採点するモードは、最後の問題に答えると結果を読み上げ、記録を残します（11章）。

◆ 試聴（F2）

音が自分の周りを、正面から左回り（上から見て反時計回り）に回り続けます。もう一度 F2 で止まります。設定を変えると、回っている音にその場で反映されるので、設定の効き方を確かめるのに使えます。

◆ 8方向の聞き比べ（Ctrl+Shift+F2）

採点しません。テンキーの1から9（5を除く）を押すと、その方向の音が水平に鳴ります。クイズの前に、前と後ろや斜めの聞こえ方の違いを、好きな順に何度でも聞けます。押したときは読み上げないので、音に集中できます。F6 キーか、別のモードのキーで終わります。

◆ 上下の聞き比べ（Shift+F2）

採点しません。テンキーのスラッシュで真上、8で上（45度）、5で水平、2で下（45度）の音が、正面で鳴ります。上下の聴き取りの前に、4つの高さを聞き比べるためのモードです。設定の「HRTF」で実測の耳介（実測 Viking）を選んでいるときだけ使えます。

◆ クイズ（F3）

いろいろな方向から音が鳴るので、方向を答えます。方向の数は設定の「難易度」で選びます（左右のみ、前後左右、8方向、12方向）。結果では、正答率のほかに、前と後ろを取り違えた数を数えます。前後の取り違えは、他人の耳の形のデータで聞くと最も起きやすい誤りです。

◆ 訓練（F7）

間違えた方向を重点的に出し直します。間違えると正解の方向の音をもう一度鳴らすので、違いをよく聞いてください。決まった数だけ続けて正解すると終わります。

◆ 回る向きの聴き取り（Ctrl+F2）

音が自分の周りを3秒かけて半周するので、回る向きを答えます。水平に回る音は、テンキーの4で左回り（前から左、後ろ、右の順）、6で右回りと答えます。頭上を越える音は、8で後ろから前へ、2で前から後ろへと答えます。回り始めの方向は毎回変わり、前と後ろを取り違えると回る向きが逆に聞こえるので、前後の聞き分けを動きで試せます。頭上を越える音は、実測の耳介を選んでいるときだけ出ます。

◆ 上下の聴き取り（Shift+F3）と正面固定の上下の聴き取り（Ctrl+F3）

音の高さを、真上・上・水平・下の4つから答えます（テンキーのスラッシュ、8、5、2）。Shift+F3 は方位を難易度の方向から混ぜ、Ctrl+F3 は毎回正面から鳴らして高さだけを変えます。実測の耳介を選んでいるときだけ使えます。下は45度までです（実測データが下45度までしかないため）。
基準音（テンキーのアスタリスクでオンとオフ、起動時はオン）がオンのときは、問題の音の前に、同じ方位の水平の音を鳴らします。2つ目の音が1つ目より上か下かを比べて答えられます。

◆ 耳介の選定（F8）と上下用の耳介の選定（Ctrl+F8）

耳の形のデータ（耳介）を何種類か順に試し、自分に合うものを探します。F8 は方向（前後）で、Ctrl+F8 は高さ（上下）で試します。毎回、いまの最良の耳介を比べる基準として入れます（回を重ねると聞き手も上達するので、同じ回の中で比べないと差が分かりません）。結果は通算で積み上がり、F10 キーで順位を読み上げます。何回かに分けて全種類を試してください。
通算でよかった耳介は、設定の「HRTF」で選んでください。選定が終わると、試していた耳介から、設定で選んでいる耳介に戻ります。

◆ 首振りの効果測定（F11）

首振り（8章）ありの問題と、なしの問題を1問ごとに交互に出し、それぞれの正答率を比べます。どちらの条件かは出題のときには言いません。実施中は、矢印キーで向きを変えないでください（条件の比較が正確でなくなります）。

◆ 問題数

■ 8. 聞き分けを助ける設定

他人の耳の形のデータで聞くと、前と後ろ、上と下を取り違えやすくなります。設定の欄に、それを助ける工夫が6つあります。数値の詳しい中身は、同じフォルダの CUES.md にあります。

◆ 前後を助けるもの

【前後の強調（パーセント、起動時は35）】
  後ろにある音ほど小さく、こもった音にします。35パーセントでは、真後ろの音が約0.65倍の大きさになり、高い音域が少し削られます。真上と真下の音には効きません。
【首振り（起動時は標準）】
  頭を小さく左右に振る揺れを自動で加えます。頭が動くと、前の音と後ろの音が逆向きに動くので、耳の形の個人差に関係なく前後が分かります。最も確実な手がかりです。

◆ 上下を助けるもの

【上下の強調（パーセント、起動時は0）】
  上の音ほど高い音域を明るく、下の音ほどこもらせます。自然な聞こえ方ではありませんが、覚えやすい手がかりです。顔から見た高さで決まるので、Page Up で上を向くと水平の音が暗く聞こえます。
【首かしげ（起動時はなし）】
  首を左右の肩へ交互に傾ける揺れを自動で加えます。上の音と下の音が左右へ逆向きに動き、正面の水平の音は動きません。
【床の反射（起動時はオフ）】
  床で跳ね返った音を加えます。高い音ほど、直接の音と反射音の時間差が長くなります。設定の「空間」を選んでいるときは、空間に床の反射が含まれるのでオフにしてください。
【基準音（テンキーのアスタリスク、起動時はオン）】
  上下の聴き取りで、問題の音の前に同じ方位の水平の音を鳴らします（7章）。

◆ 使い方の目安

最初は起動時のまま試し、迷う方向があれば1つずつ足して効き方を確かめてください。首振りの効果は F11 で測れます。上下が分かりにくいときは、上下の強調を30から50パーセントにすると分かりやすくなることがあります。

◆ 精密な残響

設定の「精密な残響」をオンにすると、閉じた部屋の後期残響を、精密に計算した響きにします。用意した閉じた部屋は計算済みなので、すぐに切り替わります。自分で作った閉じた部屋は、pyroomacoustics が入っていれば裏で十数秒かけて計算し、その間は軽い版で鳴らし、できたら切り替えます。計算した響きは保存され、次からはすぐ使えます。建物の間の道のように開いた面のある空間と、家具や人を置いた空間は、軽い版のままです。

■ 10. 空間と残響を自分で作る

設定の欄の「空間を自分で作る」（Alt+E）と「残響を自分で作る」（Alt+G）のボタンで、専用の窓が開きます。どちらも、値を調整して名前を付けて保存すると、設定の「空間」と「残響」の選択肢に「自作: 名前」として並び、選ばれた状態になります。

◆ 窓の使い方

1. 最初の欄「元にする響き」で、用意された空間や残響、または自分で作ったものを選びます。その値が下の欄に入ります
2. 下の欄の値を変えます。「いまの設定」の欄に、いまの値での残響の長さなどが文で出ます（Tab で戻れば確かめられます）
3. 「この設定で鳴らす」（Alt+P）で、保存する前に正面の音で聞けます
4. 「名前」の欄に名前を入れ、「保存」（Alt+S）を押します。同じ名前で保存すると上書きします
5. Escape か「閉じる」で窓を閉じます。設定の欄で選んでいる響きに戻ります

自分で作ったものを消すときは、名前の欄にその名前を入れて「削除」（Alt+D）を2回押します（確認の窓は出ません）。
材質の一覧は、床なら床に合う材質、天井なら天井に合う材質が上に並び、それ以外は「その他」を頭に付けて下に並びます。全部の材質は付録にあります。家具の量は、種類が「部屋」のときだけ選べます。

・欄: 保存（Alt+S） / 種類: ボタン / 範囲や選択肢: 押すと実行する
・欄: 削除（Alt+D） / 種類: ボタン / 範囲や選択肢: 押すと実行する
・欄: 閉じる / 種類: ボタン / 範囲や選択肢: 押すと実行する

◆ 保存先

自分で作った空間と残響は、このフォルダの settings フォルダの user_presets.json に保存されます。このファイルが壊れても、起動は止まりません。読めないファイルは名前の後ろに .broken を付けて残し、空の状態から始めます。そのことは起動したときの「状況」の欄の先頭に書かれます。

■ 11. 結果の記録

採点するモードが終わると、結果をこのフォルダの logs フォルダに自動で保存し、保存したファイルの名前を読み上げます。ファイルの名前は、モードの名前、日付、時刻をつないだものです（例えば quiz_20261016_093000.txt）。モードの名前は、クイズが quiz、訓練が training、耳介の選定が calib、上下用の耳介の選定が calib_elev、首振りの効果測定が ab、上下の聴き取りが elev、正面固定の上下の聴き取りが elev_front、回る向きの聴き取りが rotation です。
ファイルの中身はテキストで、モード、日時、そのときの設定、結果の要約、1問ずつの結果の順に並んでいます。メモ帳などで読めます。表示の言語が英語のときは、ファイルの中身も英語になります。
耳介の選定の通算の成績は、logs フォルダの pinna_records.json（方向）と pinna_records_elev.json（高さ）に積み上がります。通算をやり直したいときは、ツールを閉じてからこのファイルを消してください。

■ 12. キー操作の一覧

この一覧は、ツールの F1 の説明と、ツールが実際に使っている対応表から作っています。

◆ モードのキー

モードを始めるキーです。11項目あります。
【F2】
  試聴の開始と停止 (音が周囲を回ります)
【Shift+F2】
  上下の聞き比べ (採点なし)。テンキーのスラッシュで真上、8で上、5で水平、2で下の音が正面で鳴ります。テストの前に4つの高さを聞き比べるためのモードです。押したときは読み上げません。
【Ctrl+Shift+F2】
  8方向の聞き比べ (採点なし)。テンキーの1から9 (5を除く) で、その方向の音が水平に鳴ります。キーの並びがそのまま方向の配置です。8で前、2で後ろ、4で左、6で右。方向は、いまの自分から見た向きです。押したときは読み上げません。
【F3】
  クイズ (難易度に応じて10問から24問、成績を測る)
【F7】
  訓練 (間違えた方向を重点的に、連続正解で終了)
【F8】
  耳介の選定 (複数の耳介を試して合うものを探す)。毎回、現在の最良を基準として同席させます。回を重ねると聞き手も上達するため、同じ回の中で比べないと差が分かりません。結果は通算で積み上がるので、何回かに分けて全種類を試せます。
【F11】
  首振りの効果測定 (ありとなしを1問ごとに交互に出して比べる)。どちらの条件かは出題時には言いません。実施中は矢印キーでの向きの変更を控えると、条件の比較が正確になります。
【Shift+F3】
  上下の聴き取り (真上・上・水平・下の4択)。実測 Viking を選んでいるときだけ使えます。方位は難易度の方向から選びますが、答えるのは高さだけです。
【Ctrl+F3】
  正面固定の上下の聴き取り (真上・上・水平・下の4択)。音は毎回正面から鳴り、変わるのは高さだけです。上下の聞こえ方の違いそのものを聞き比べるためのモードです。
【Ctrl+F8】
  上下用の耳介の選定。F8 の上下版です。正面固定の上下4択で耳介を順に試します。通算成績は前後用とは別に積み上がり、F10 で続けて読み上げます。
【Ctrl+F2】
  回る向きの聴き取り (24問)。音が自分の周りを半周します。水平に回る音は、左回りか右回りかを答えます。左回りは上から見て反時計回り、前から左、後ろ、右の順です。回り始めの方向は毎回変わります。前と後ろを取り違えると、回る向きが逆に聞こえます。頭上を越える音は、前から後ろへか、後ろから前へかを答えます (実測 Viking を選んでいるときだけ出題します)。

◆ 操作のキー

どのモードでも使えるキーです。9項目あります。
【テンキーの0】
  繰り返し再生のオンとオフ (起動時はオン)。オンのときは、テンキーで答えるまで出題音を間を空けて鳴らし続けます。読み上げに紛れて聞き逃しても待てば聞けます。
【テンキーの*】

【F4】

【F5】

【F6】

【F9】

【F10】

【F1】

■ 13. ライブラリの使い方（ゲームに組み込む）

この章は、Python で作るゲームやツールに audiospace を組み込む人向けです。ここでは主な使い方を紹介します。すべての機能と注意点は、同じフォルダの README.md にあります。

◆ 入れ方

このフォルダで次を実行します。実機で音を出すには playback を付けます。

    python -m pip install -e ".[playback]"

配布の wheel（audiospace-0.7.0-py3-none-any.whl）を使う場合は、ファイルのあるフォルダで次を実行します。wheel には実測の耳介20種類のデータは入らず、既定の耳介（耳介E、水平面だけ）が入ります。

    python -m pip install "audiospace-0.7.0-py3-none-any.whl[playback]"

◆ 座標と向き

座標はメートルで、x が東、y が北、z が上です。聞き手の向き（yaw_deg）は北から反時計回りの角度で、0なら北を向き、90なら西（左）を向きます。

◆ 音を鳴らす

    from audiospace import SpatialPlayer

    player = SpatialPlayer.open(head_wobble="clear")   # 音の出力を開く（首振りあり）
    h = player.play("beacon.wav", position=(3.0, 4.0, 0.0), loop=True)
    player.play_ui("menu_move.wav")                    # メニューの音は方向を付けない
    player.set_listener((0.0, 0.0, 0.0), yaw_deg=90)   # 聞き手が左を向く
    player.engine.set_source_position(h, (0.0, 6.0, 0.0))   # 音を動かす
    player.stop_sound(h, fade_ms=30)                   # 30ミリ秒で消して止める
    print(player.status())                             # 読み上げ用の状態の文
    player.stop()

play には wav などのファイルの名前か、音の配列を渡せます。同じファイルは一度読めば覚えておくので、何度鳴らしても読み直しません。鳴り終わった音は自動で片付きます。

◆ 前後と上下を聞き分けやすくする

    player.set_emphasis(front_back=0.35, elevation=0.35)   # 前後の強調と上下の強調（0〜1）

    from audiospace import ROLL_PRESETS
    player.engine.set_roll_wobble(ROLL_PRESETS["clear"])   # 首かしげ（振り幅12度）

◆ 響きを付ける

    player.set_reverb("hall")                # 方向のない残響（9章の名前）
    player.set_space("wood_room")            # 材質つきの空間（名前は space_labels() で得られる）
    player.set_space(None)                   # 空間の響きを外す

空間を切り替えると、前の響きは自然に鳴り終わり、新しい響きへなめらかにつながります。場所ごとに空間を登録して、聞き手のいる場所で自動で切り替えることもできます（README.md の「場所の移動」）。

◆ 家具や人を置く

    from audiospace import space_preset, furnish_counts

    room = space_preset("wood_room")
    counts = furnish_counts(room.size[0] * room.size[1], "normal")   # 床の広さに合わせた家具
    player.set_space(room.with_contents(dict(counts, person=4)))    # 家具と4人を置く

ゲームの中で物を置いたり人が入ってきたりしたら、中身を替えた空間を渡し直します。響きはなめらかに切り替わります。

◆ 空間と残響を設計図から作る

空間と残響は、JSON にそのまま書ける辞書（設計図）からも作れます。定位確認ツールで作って保存したもの（settings フォルダの user_presets.json）も、この形です。

    from audiospace import space_from_spec, reverb_from_spec

    room = space_from_spec({
        "kind": "room",                     # room（部屋）、street（建物の間の道）、open（何もない場所）
        "size": [6.0, 5.0, 2.8],            # 幅、奥行き、高さ（メートル）
        "materials": {"floor": "wood_16mm", "ceiling": "plasterboard",
                      "north": "glass_window", "south": "wooden_door",
                      "west": "brickwork", "east": "curtains_velvet"},
        "contents": {"sofa": 1, "person": 2}})
    player.set_space(room)
    player.set_reverb(reverb_from_spec({"rt60": 2.5}, player.engine.sample_rate))

面の名前は、聞き手が北を向いているとして、north が前の壁、south が後ろの壁、west が左の壁、east が右の壁です。材質の名前は付録の「名前（プログラム）」の列にあります。値が正しくないときは、どこが正しくないかを表示の言語の文で知らせます。

◆ 表示の言語

読み上げ名・状態・誤りの説明などの文は、OS の表示言語が日本語なら日本語、それ以外なら英語になります（2章）。決めたいときは、プログラムを起動する前に環境変数 AUDIOSPACE_LANG を ja か en にします。FURNISH_LEVELS などの名前の一覧は audiospace を読み込んだときに作るので、動いている途中では言語を変えられません。いまの言語は audiospace.language() で分かります。

◆ 音を出さずに試す

環境変数 AUDIOSPACE_SILENT を 1 にすると、音の出力を開かずに動きます。自動のテストに使います。音の出力を開かないエンジン（SpatialEngine）を直接使えば、出来上がった音を配列として受け取れます。

◆ 配布するときの表示

既定の耳介のデータは CC BY 4.0 のデータなので、ゲームに組み込んで配るときは、作品の中（「このソフトについて」の画面や説明書など）に出典を表示する必要があります。文面は attribution() で得られます（15章）。

■ 14. 困ったとき

【音が出ない】
  ヘッドホンが Windows の既定の再生装置になっているか確かめてください。また、環境変数 AUDIOSPACE_SILENT を 1 にしていると、音を出しません（自動のテスト用の設定です。コマンドプロンプトで set AUDIOSPACE_SILENT=1 を実行した場合など）。起動用の bat から起動すれば、この設定は消えます。
【ツールが何も読み上げない】
  accessible_output2 が入っていない可能性があります。3章のコマンドをもう一度実行してください。画面の欄はスクリーンリーダーで読めます。
【テンキーで答えても何も起きない】
  NumLock がオフになっていないか確かめてください。また、問題の音が鳴る前（答えた直後の読み上げの間を含む）は、答えを受け付けません。
【上下の聴き取りや上下の聞き比べが始まらない】
  設定の「HRTF」で、実測の耳介（実測 Viking）を選んでください。合成のデータには上下の情報がありません。
【精密な残響が軽い版のまま】
  開いた面のある空間と、家具や人を置いた空間は、軽い版になります。自分で作った閉じた部屋は、pyroomacoustics が入っていないと計算できません。F9 キーの読み上げに、どの響きで鳴っているかが入っています。
【前と後ろの区別がつかない】
  首振りを「標準」か「強め」にして、左右の矢印キーで向きを変えながら聞いてください。耳介の選定（F8）で自分に合う耳介を探すと、改善することがあります。
【表示が英語になる（または日本語にしたくない）】
  表示の言語は Windows の表示言語に合わせます。決めたいときは、環境変数 AUDIOSPACE_LANG を ja か en にします（2章）。例えばコマンドプロンプトで set AUDIOSPACE_LANG=ja を実行し、そのコマンドプロンプトから起動します。
【自分で作った空間が消えた】
  保存ファイルが壊れていると、空の状態から始めます。壊れたファイルは settings フォルダに .broken を付けて残っています（10章）。

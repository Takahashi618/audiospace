audiospace 0.7.1 Manual

Author: Takahashi. This is the English edition of the manual, written in October 2026.

audiospace is a 3D audio component (a library) for games and tools for blind and visually impaired people, meant to be heard on headphones. It comes with the Localization Tool, which lets you check which direction sounds come from and how rooms sound. Both work with the keyboard and a screen reader (tested with NVDA and PC-Talker) alone.

Every chapter has a heading, so you can move through this document by headings. A plain text edition with the same content is also included (Manual (English).txt). The Japanese edition is マニュアル.html.

Appendix: List of materials

1. Introduction

Sounds on headphones normally seem to play inside your head. audiospace processes sounds so that they arrive from a chosen direction and distance outside your head (binaural processing). It uses measured data on how the shape of the ear changes sound (head-related transfer functions, or HRTFs), so it can place sounds not only left and right, but also in front, behind, above and below.

What it can do

  • Place sounds anywhere around the listener, at any distance, and move them
  • Add room reverb. The materials of the room (wood, concrete, carpet and so on) and the furniture and people in it change the sound
  • Help tell front from back and up from down (making sounds behind more muffled, making sounds above brighter, small automatic head movements, and more)
  • Let you choose, from measured data of 20 different ear shapes, the one that suits you

The Localization Tool

The Localization Tool is a window for checking which direction sounds seem to come from, and for practising telling them apart. You can measure your accuracy with a quiz, choose the ear-shape data that suits you, and compare how rooms sound. Game developers can use it to check how sounds will be heard.

How to read this manual

If you only want to use the Localization Tool, read from chapter 2 onwards. If you want to use the library in a game, install the components in chapter 3 and then go to chapter 13. Chapter 12 lists all the keys.

2. Requirements

  • Tested on Windows 11, with the NVDA and PC-Talker screen readers
  • Python 3.10 or later (the author uses 3.14.5)
  • Headphones. With speakers, the left and right sounds mix and directions cannot be heard

Components used

The components are all installed by the steps in chapter 3. The library alone needs only numpy and scipy. The Localization Tool also needs these four:

  • wxPython: builds the window
  • accessible_output2: makes your screen reader speak. The tool works without it, but the tool's own announcements (correct, wrong and so on) are not spoken
  • sounddevice: plays the sound
  • sofar: reads the files of measured HRTFs (.sofa)

In addition, if pyroomacoustics is installed, the reverb of rooms you design yourself can be computed precisely (chapter 9). Without it, the precise reverb of the provided rooms still works.

The versions tested by the author are wxPython 4.2.5, numpy 2.4.6, scipy 1.17.1, sofar 1.2.3, sounddevice 0.5.5, accessible_output2 0.17 and pyroomacoustics 0.10.1.

Language

The Localization Tool and the library show their text in Japanese when the display language of Windows (or the preferred language of macOS) is Japanese, and in English otherwise. This covers the window, the spoken announcements, the results and the saved files. To choose the language yourself, set the environment variable AUDIOSPACE_LANG to en (English) or ja (Japanese) before starting. The language is decided when the program starts, so restart it after changing this.

3. Setting up

There are four steps. The last one is optional.

3.1 Put the folder in place

Extract the distributed zip file and put the resulting folder in a folder you can write to, such as Documents. Do not put it inside Program Files. The Localization Tool writes saved results (the logs folder) and your own spaces (the settings folder) inside this folder.

To extract the zip file in File Explorer, select it, open the context menu with the Applications key (or Shift+F10), and choose Extract All.

3.2 Install Python

Install Python for Windows from python.org. The first screen of the installer has a check box called Add python.exe to PATH. Check it before pressing Install Now. If you do not, the next step will say that python cannot be found.

3.3 Install the components

Open a command prompt in this folder and run one command.

  1. Open this folder in File Explorer
  2. Press Alt+D to move to the address bar, type cmd and press Enter. A command prompt opens in this folder
  3. Type the following line and press Enter. It takes a few minutes; it has finished when a line starting with Successfully installed appears
python -m pip install -e ".[app]"

If it says that python cannot be found, run the same line with py instead of python at the start. The tool will then start with that same Python in chapter 4 (the launcher tries python first and uses py if python does not work).

If you want the reverb of rooms you design yourself to be computed precisely, also run the following (optional).

python -m pip install pyroomacoustics

3.4 Check that it works (optional)

Running the following in the same command prompt starts the automatic tests. They play no sound. They take a few minutes; if the last line says all passed, the components are installed correctly (the lines before it are in Japanese).

python -X utf8 tests\run_all.py

4. Starting and quitting

Open Start Localization Tool.bat in the folder to start the Localization Tool: select the file in File Explorer and press Enter. The file 定位確認ツールを起動.bat does the same thing (it is the Japanese name of the same launcher).

A window called Localization Tool - audiospace opens, with the focus in the Status log field. At start this field contains the keyboard help, which you can read with the up and down arrows. Press F1 to read the same help in a window of its own (Escape closes it).

You can also start it from a command prompt in this folder:

python -X utf8 demo\localization_app.py

To quit, press Escape in the window.

If it does not start

If no window opens and a black window shows some messages and stops, something is missing. Usually the components of chapter 3 are not installed. Press any key to close the black window. See also chapter 14.

5. The screen

There is one window. From top to bottom it has the settings, the Status log field and the Results list. Tab moves through them from the top. The key in brackets after the name of an item (for example Alt+H) moves straight to that item.

  • Settings: the HRTF, the type of sound, reverb, the settings that help you tell directions apart, the difficulty and so on. Changes take effect at once
  • Status log: a read-only field with the guidance for each mode and the results
  • Results: the result of each answer, one per line

Settings are not saved; every time the tool starts they return to their starting values. F9 reads the current settings.

6. Basic use

In every mode, you answer with the numeric keypad after the sound plays. Turn NumLock on (with NumLock off, the keypad keys work as arrows and other keys). Chapter 12 lists the answer keys.

Answering

In the modes where you answer a direction, the keys of the numeric keypad are laid out like the directions: 8 is front, 2 is back, 4 is left, 6 is right, 7 is front left, 9 is front right, 1 is back left and 3 is back right. As soon as you answer, it says something like "Question 1: Correct. The correct answer was front.", and after a short pause the next question plays.

If you miss the sound

  • F4 plays the current question again
  • When Repeat is on (numpad 0 turns it on and off; it is on at start), the question sound keeps playing with pauses until you answer. If speech covers it, just wait
  • F6 stops the sound and the repeating

Turning

The left and right arrows turn you 15 degrees on the spot. The sounds do not move, so when you turn, sounds in front and sounds behind move in opposite directions. This helps when you are unsure whether a sound is in front or behind. Answer with the direction as seen from where you face now.

Page Up and Page Down turn your face 15 degrees up or down (up to straight up or straight down, 90 degrees). In the up/down tests, answer with the height of the sound as seen from your body, whichever way your face points.

Keys that read things out

  • F5: the results of the current mode
  • F9: the current settings
  • F10: the running totals of the ear-shape data (pinnae) (chapter 7)
  • F1: the keyboard help window

7. The modes

There are 3 modes that are not scored and 8 that are. A key starts each mode, and pressing the key of another mode switches to it. When you answer the last question of a scored mode, it reads the results and saves them (chapter 11).

Preview (F2)

A sound keeps circling around you, counterclockwise from the front (as seen from above). Press F2 again to stop. Changes to the settings apply to the circling sound at once, so this is a good way to hear what each setting does.

Compare 8 directions (Ctrl+Shift+F2)

Not scored. Numpad 1 to 9 (except 5) play a level sound from that direction. Before a quiz, you can listen to the difference between front, back and the diagonals as often as you like, in any order. Pressing a key does not speak, so you can focus on the sound. F6 or the key of another mode ends it.

Compare heights (Shift+F2)

Not scored. Numpad slash plays a sound straight up, 8 up (45 degrees), 5 level and 2 down (45 degrees), all in front of you. Use it to compare the four heights before an up/down test. It works only when a measured pinna (Measured Viking) is chosen in HRTF.

Quiz (F3)

Sounds play from various directions and you answer the direction. Choose the number of directions in Difficulty (left and right only, 4 directions (front, back, left and right), 8 directions or 12 directions). Besides your accuracy, the results count how often you confused front and back. This is the most common mistake when listening with someone else's ear-shape data.

Training (F7)

Directions you get wrong come back more often. After a wrong answer, the correct direction plays again, so listen closely for the difference. It ends after a set number of correct answers in a row.

Rotation test (Ctrl+F2)

A sound travels half a circle around you in 3 seconds, and you answer which way it went. For a level circle, answer numpad 4 for counterclockwise (front, then left, back, right) or 6 for clockwise. For a sound passing overhead, answer 8 for back to front or 2 for front to back. The starting point changes every time, and confusing front and back makes the direction sound reversed, so this tests front and back through movement. Sounds passing overhead are asked only when a measured pinna is chosen.

Up/down test (Shift+F3) and up/down test from the front (Ctrl+F3)

Answer the height of the sound: straight up, up, level or down (numpad slash, 8, 5 and 2). Shift+F3 mixes in the directions of the difficulty; Ctrl+F3 always plays from the front and changes only the height. They work only when a measured pinna is chosen. Down goes only to 45 degrees, because the measured data stops there.

When the reference sound is on (numpad asterisk turns it on and off; it is on at start), a level sound from the same direction plays before the question sound, so you can answer whether the second sound is higher or lower than the first.

Choose a pinna (F8) and choose a pinna for up and down (Ctrl+F8)

Tries several sets of ear-shape data (pinnae) one after another, to find the one that suits you. F8 tests directions (front and back); Ctrl+F8 tests heights (up and down). Every round includes your current best pinna as a reference (listeners improve as they go, so differences only show within the same round). Results add up over time, and F10 reads the ranking. Try them all over several rounds.

Choose the pinna that did best in HRTF in the settings. When a round ends, the tool switches from the pinna it was trying back to the one chosen in the settings.

Head wobble measurement (F11)

Questions with head wobble (chapter 8) and without it alternate, and the accuracy of each is compared. It does not say which condition a question uses. Do not turn with the arrow keys during the test (it makes the comparison less accurate).

8. Settings that help you tell directions apart

With someone else's ear-shape data, it is easy to confuse front with back and up with down. The settings have six aids for this. The details of the numbers are in CUES.en.md in the same folder.

Aids for front and back

Front/back emphasis (percent, 35 at start)
The further behind a sound is, the quieter and more muffled it becomes. At 35 percent, a sound straight behind is about 0.65 times as loud, with the high frequencies slightly cut. It does not affect sounds straight above or below.
Head wobble (Standard at start)
Adds a small automatic side-to-side movement of the head. When the head moves, sounds in front and sounds behind move in opposite directions, so you can tell front from back regardless of the shape of your ears. This is the most reliable aid.

Aids for up and down

Up/down emphasis (percent, 0 at start)
Makes higher sounds brighter and lower sounds more muffled. It is not how things naturally sound, but it is easy to learn. It follows the height as seen from your face, so facing up with Page Up makes level sounds darker.
Head tilt (Off at start)
Adds an automatic sway of tilting your head toward each shoulder in turn. Sounds above and below move left and right in opposite directions, and level sounds in front do not move.
Floor reflection (off at start)
Adds the sound that bounces off the floor. The higher the sound, the longer the gap between the direct sound and the reflection. When a Space is chosen, it already includes the floor reflection, so turn this off.
Reference sound (numpad asterisk, on at start)
In the up/down tests, plays a level sound from the same direction before the question sound (chapter 7).

Getting started with the aids

Try the starting settings first. If some directions are confusing, add one aid at a time and listen to its effect. F11 measures the effect of head wobble. If up and down are hard to tell apart, setting Up/down emphasis to 30 to 50 percent may help.

9. Reverb and spaces

There are two ways to add the sound of a room. Reverb adds only the length of the echo. Space also creates where each reflection comes from, when it arrives and how it sounds. While a space is chosen, the Reverb setting is not used.

Reverb

Creates reverb without direction from the size of a room and how much it absorbs. It is light to compute.

Spaces

Each of the six surfaces (floor, ceiling and four walls) has a material. Sound that bounces off a wall or the floor (early reflections) arrives from that surface's direction, coloured by its material. The length of the echo that follows (late reverb) also comes from the materials. Wood absorbs low sounds and carpet absorbs high sounds, so rooms of the same size can sound different.

Furniture amount and number of people

Even in a room of the same size, furniture and people change the sound. Furniture amount and Number of people in the settings add furniture and people to the chosen space. The reverb becomes shorter and quieter by as much as they absorb, and reflections from the floor and walls become weaker by as much as they block. Furniture works only in closed rooms; people are added to any space. The values are rough estimates to change the sound broadly, and where things stand is not modelled.

Precise reverb

Turning on Precise reverb in the settings replaces the late reverb of closed rooms with a precisely computed one. The provided closed rooms are computed already, so they switch at once. For closed rooms you design yourself, if pyroomacoustics is installed, it takes ten seconds or more to compute in the background; meanwhile the light version plays, and it switches when ready. Computed reverbs are saved and are ready at once next time. Spaces with open sides, such as a street between buildings, and spaces with furniture or people keep the light version.

10. Designing your own spaces and reverbs

The Design a space (Alt+E) and Design a reverb (Alt+G) buttons in the settings open a window of their own. In both, when you adjust the values and save them with a name, they appear in the Space and Reverb choices as "Yours: name", already chosen.

Using the window

  1. In the first field, Start from, choose a provided space or reverb, or one you made. Its values fill the fields below
  2. Change the values in the fields. The Current settings field describes the result in words, such as the length of the reverb (Tab back to it to check)
  3. Play with these settings (Alt+P) lets you hear it from the front before saving
  4. Type a name in the Name field and press Save (Alt+S). Saving with the same name replaces it
  5. Escape or Close closes the window, and the sound returns to what is chosen in the settings

To delete one you made, type its name in the Name field and press Delete (Alt+D) twice (no confirmation window opens).

In the material lists, materials that suit the surface come first (floor materials for the floor, ceiling materials for the ceiling); the rest follow, starting with "Other". All the materials are in the appendix. Furniture amount can be chosen only when the kind is Room.

Where they are saved

Your own spaces and reverbs are saved in user_presets.json in the settings folder of this folder. If this file becomes damaged, the tool still starts: it keeps the unreadable file with .broken added to its name and starts with none. This is mentioned at the top of the Status log field at start.

11. Saved results

When a scored mode ends, the results are saved automatically in the logs folder of this folder, and the name of the saved file is read out. The file name joins the name of the mode, the date and the time (for example quiz_20261016_093000.txt). The mode names are quiz for the quiz, training for training, calib for choosing a pinna, calib_elev for choosing a pinna for up and down, ab for the head wobble measurement, elev for the up/down test, elev_front for the up/down test from the front, and rotation for the rotation test.

The file is plain text, in the display language of the tool, with the mode, the date and time, the settings at the time, a summary of the results and the result of each question, in that order. You can read it in Notepad.

The running totals of choosing a pinna build up in pinna_records.json (directions) and pinna_records_elev.json (heights) in the logs folder. To start the totals again, close the tool and delete these files.

Choose a pinna (tries several pinnae to find one that suits you). Every round includes the current best as a reference. Listeners improve as they go, so differences only show within one round. Results add up, so you can try them all over several rounds.
F11
Measure the head wobble effect (alternates with and without). It does not say which condition a question uses. Avoid turning with the arrow keys during the test for a fairer comparison.
Shift+F3
Up/down test (straight up, up, level or down). Only with a measured Viking HRTF. The directions come from the difficulty, but you answer only the height.
Ctrl+F3
Up/down test from the front (straight up, up, level or down). The sound always comes from the front, and only the height changes. Use it to learn how the heights sound different.
Ctrl+F8
Choose a pinna for up and down. The up/down version of F8. It tries pinnae one after another with the up/down test from the front. Its totals are kept apart from the front/back ones, and F10 reads them after those.
Ctrl+F2
Rotation test (24 questions). A sound travels half a circle around you. For a level circle, answer counterclockwise or clockwise. Counterclockwise is as seen from above: front, then left, back, right. The starting point changes every time. Confusing front and back makes the direction sound reversed. For a sound passing overhead, answer back to front or front to back (asked only with a measured Viking HRTF).

13. Using the library in a game

This chapter is for people who want to use audiospace in a game or tool written in Python. It introduces the main features. All the features and details are in README.en.md in the same folder.

Installing

Run the following in this folder. Add playback to play sound on a real device.

python -m pip install -e ".[playback]"

To use the distributed wheel (audiospace-0.7.1-py3-none-any.whl), run the following in the folder that has the file. The wheel does not include the measured data of the 20 pinnae; it includes the default pinna (pinna E, horizontal plane only).

python -m pip install "audiospace-0.7.1-py3-none-any.whl[playback]"

Coordinates and facing

Coordinates are in metres: x is east, y is north and z is up. The listener's facing (yaw_deg) is an angle counterclockwise from north: 0 faces north and 90 faces west (left).

Playing sounds

from audiospace import SpatialPlayer

player = SpatialPlayer.open(head_wobble="clear")   # open the audio output (with head wobble)
h = player.play("beacon.wav", position=(3.0, 4.0, 0.0), loop=True)
player.play_ui("menu_move.wav")                    # menu sounds get no direction
player.set_listener((0.0, 0.0, 0.0), yaw_deg=90)   # the listener turns left
player.engine.set_source_position(h, (0.0, 6.0, 0.0))   # move the sound
player.stop_sound(h, fade_ms=30)                   # fade out over 30 ms and stop
print(player.status())                             # a status line to read aloud
player.stop()

play takes the name of a file such as a wav, or an array of samples. A file is read once and remembered, so playing it many times does not read it again. Sounds that have finished are cleaned up automatically.

Helping to tell front, back, up and down apart

player.set_emphasis(front_back=0.35, elevation=0.35)   # front/back and up/down emphasis (0 to 1)

from audiospace import ROLL_PRESETS
player.engine.set_roll_wobble(ROLL_PRESETS["clear"])   # head tilt (12 degrees)

Adding reverb

player.set_reverb("hall")                # reverb without direction (names in chapter 9)
player.set_space("wood_room")            # a space with materials (names from space_labels())
player.set_space(None)                   # remove the space

When you switch spaces, the old reverb dies away naturally and the new one fades in smoothly. You can also register a space for each place and switch automatically to the one where the listener is (see Moving between places in README.en.md).

Adding furniture and people

from audiospace import space_preset, furnish_counts

room = space_preset("wood_room")
counts = furnish_counts(room.size[0] * room.size[1], "normal")   # furniture to suit the floor area
player.set_space(room.with_contents(dict(counts, person=4)))    # furniture and 4 people

When things are placed or people come in during the game, pass the space again with the new contents. The sound changes smoothly.

Making spaces and reverbs from a design

Spaces and reverbs can also be made from a dictionary (a design) that can be written as JSON as it is. What you make and save in the Localization Tool (user_presets.json in the settings folder) has the same form.

from audiospace import space_from_spec, reverb_from_spec

room = space_from_spec({
    "kind": "room",                     # room, street (between buildings) or open
    "size": [6.0, 5.0, 2.8],            # width, depth, height (metres)
    "materials": {"floor": "wood_16mm", "ceiling": "plasterboard",
                  "north": "glass_window", "south": "wooden_door",
                  "west": "brickwork", "east": "curtains_velvet"},
    "contents": {"sofa": 1, "person": 2}})
player.set_space(room)
player.set_reverb(reverb_from_spec({"rt60": 2.5}, player.engine.sample_rate))

Taking the listener as facing north, north is the front wall, south the back wall, west the left wall and east the right wall. The material names are in the Name (program) column of the appendix. If a value is wrong, the error message says which one, in the display language.

Display language

Text meant for people, such as names, status lines and error messages, is Japanese when the operating system's display language is Japanese and English otherwise (chapter 2). To choose, set AUDIOSPACE_LANG to en or ja before starting the program. Lists of names such as FURNISH_LEVELS are made when audiospace is imported, so the language cannot be changed while the program is running. audiospace.language() returns the language in use.

Trying without sound

Setting the environment variable AUDIOSPACE_SILENT to 1 makes it run without opening the audio output. It is used for automatic tests. If you use the engine (SpatialEngine) directly, which does not open the audio output, you get the finished sound as an array.

Credits when you distribute

The default pinna data is licensed under CC BY 4.0, so when you distribute it in a game you must show where it comes from inside your product (an About screen, the manual and so on). attribution() returns the text (chapter 15).

14. Troubleshooting

There is no sound
Check that your headphones are the default playback device in Windows. Also, if the environment variable AUDIOSPACE_SILENT is set to 1, no sound plays (a setting for the automatic tests, for example after running set AUDIOSPACE_SILENT=1 in a command prompt). Starting the tool with the launcher clears this setting.
The tool does not speak
accessible_output2 may not be installed. Run the command of chapter 3 again. The fields of the window can still be read with your screen reader.
Nothing happens when I answer with the keypad
Check that NumLock is on. Also, answers are not accepted before the question sound plays (including the moment just after an answer, while the result is spoken).
The up/down tests or Compare heights do not start
Choose a measured pinna (Measured Viking) in HRTF. The synthetic data has no information about up and down.
Precise reverb stays on the light version
Spaces with open sides and spaces with furniture or people use the light version. Closed rooms you design yourself cannot be computed without pyroomacoustics. F9 reads which reverb is playing.
I cannot tell front from back
Set Head wobble to Standard or Strong, and listen while turning with the left and right arrows. Finding a pinna that suits you with Choose a pinna (F8) may also help.
The text is in the wrong language
The language follows the display language of Windows. To choose it, set AUDIOSPACE_LANG to en or ja (chapter 2), for example by running set AUDIOSPACE_LANG=en in a command prompt and then starting the tool from that command prompt.
My own spaces are gone
If the saved file is damaged, the tool starts with none. The damaged file is kept in the settings folder with .broken added to its name (chapter 10).
